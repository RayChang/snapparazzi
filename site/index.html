只對準​一個視窗。


      
原生的 macOS 指令列工具。每隔幾秒替一個 App 視窗截一張圖，把自動化流程跑過的每一步留下來，比錄影省空間得多。需要影片時，也能錄成 MP4，連同那個 App 的聲音。


      

        
在終端機貼上這一行安裝：

        

          
+-- install.sh +

          

            curl -fsSL https://raw.githubusercontent.com/RayChang/snapparazzi/main/install.sh | sh
            
          

          
++

        

        
需要 macOS 14 以上（錄影需要 15）與 Xcode Command Line Tools。安裝程式會在你的 Mac 上編譯原始碼，裝到 ~/.local/bin。

        

      

    


    
  


  




從這裡開始


    

  1. 安裝
    

    需要 macOS 14 以上（錄影需要 15），以及含 macOS 15 SDK 的 Xcode 或 Command Line Tools。還沒裝的話，先執行 xcode-select --install。接著在終端機貼上這一行：
    

    +-- install.sh +
    curl -fsSL https://raw.githubusercontent.com/RayChang/snapparazzi/main/install.sh | sh
    ++
    

    它會下載原始碼、在你的 Mac 上編譯，裝到 ~/.local/bin/snapparazzi；編譯失敗時不會動到已安裝的版本。
    2. 

  2. 允許螢幕錄製權限
    

    第一次執行時 macOS 會要求「螢幕與系統錄音」權限。到「系統設定 → 隱私權與安全性 → 螢幕與系統錄音」允許你用的終端機 App（例如 Terminal、iTerm2、Ghostty），然後重新執行命令。
    3. 

  3. 找到視窗的 ID
    

    左邊的數字就是 window ID。在其他桌面或全螢幕的視窗也會列出，並標上「不在目前桌面」。
    

    +-- zsh +
    $ snapparazzi --list
WINDOW_ID  APP — WINDOW / 應用程式 — 視窗
41324      Google Chrome — Webinar
35239      Calendar — Calendar
46635      Terminal — zsh
42133      Notes — Notes
46504      Google Chrome — YouTube  [不在目前桌面 / not on this desktop]
    ++
    4. 

  4. 開始截圖（或錄影）
    

    每 2 秒存一張圖： snapparazzi -w 41324 -i 2。要錄成影片： snapparazzi record -w 41324 --audio system。按 Ctrl-C 停止，會顯示摘要與檔案位置。
    5. 



常用指令


+-- snapparazzi +
snapparazzi --list                          # 列出視窗與 ID（含其他桌面、全螢幕）

# 截圖
snapparazzi                                 # 互動選擇視窗與間隔
snapparazzi -w 41324 -i 1.5                 # 指定視窗與間隔
snapparazzi -w 41324 -i 60 -f heic          # 更省空間
snapparazzi -w 41324 -i 1 -m 1280           # 最長邊限制為 1280 px

# 錄影（macOS 15 以上）
snapparazzi record -w 41324 --duration 10   # 只錄畫面 10 秒
snapparazzi record -w 41324 --audio system  # 加上 App 聲音，Ctrl-C 停止
snapparazzi record -w 41324 --audio both -o ~/Movies/demo.mp4  # App 聲音加麥克風，存到指定檔案

snapparazzi update                          # 更新到最新版
snapparazzi --help                          # 完整說明
++






定時截圖


每隔固定秒數把同一個視窗存成一張圖片，一直到你按 Ctrl-C。這是 Snapparazzi 最初的用途：記錄自動化流程跑過的每一步，事後一張張回頭看。 snapparazzi 與 snapparazzi capture 相同；只輸入 snapparazzi 會先列出視窗讓你選，再詢問間隔。


+-- zsh +
$ snapparazzi -w 41324 -i 2
已選擇 / selected: Google Chrome — Webinar (ID: 41324)
間隔 / interval: 2 seconds
格式 / format: jpg
最大尺寸 / max dimension: original
輸出 / output: ~/Snapparazzi/captures/20261031-101530-4821
按 Ctrl-C 停止 / Press Ctrl-C to stop.
✓ Google Chrome_20261031-101530_000001.jpg
✓ Google Chrome_20261031-101530_000002.jpg
✓ Google Chrome_20261031-101530_000003.jpg
^C
Snapparazzi 已停止 / stopped.
  成功 / succeeded: 3
  失敗 / failed: 0
  視窗不可用 / unavailable: 0
  執行時間 / elapsed: 6.1 seconds
  輸出目錄 / output: ~/Snapparazzi/captures/20261031-101530-4821
++


選項


選項說明
-l, --list列出可截取視窗與 ID 後結束
-w, --window <id>指定 window ID；省略時從清單選擇
-i, --interval <seconds>最低 0.5 秒，可用小數；省略時詢問，直接按 Enter 是 2 秒
-o, --output <directory>輸出根目錄，預設 ~/Snapparazzi/captures
-f, --format <jpg|heic|png>圖片格式，預設 jpg
-m, --max-dimension <pixels>等比例縮小到最長邊不超過這個值；預設保留原尺寸，不會放大
-h, --help完整中英雙語說明


檔案大小（實測）


預設直接輸出完整解析度的 JPG。要更小的檔案用 HEIC，要無損用 PNG； -m 會在截圖後用 macOS 內建工具等比例縮小。下表是 35 張約 2560×1410 的 Chrome 視窗樣本實測，16 小時以每秒一張（57,600 張）估算；實際大小會隨畫面內容改變。


設定平均每張16 小時、每秒一張
PNG（無損）1.30 MB74.9 GB
JPG（預設）404 KB23.3 GB
HEIC213 KB12.3 GB
JPG + -m 1280136 KB7.9 GB


每分鐘一張時，三種格式的負擔都可以忽略。每秒一張時，JPG 在速度與大小之間最均衡；HEIC 編碼較慢， -m 會多一次縮圖。最省空間的設定：


+-- zsh +
$ snapparazzi -w 41324 -i 1 -f jpg -m 1280
++


存到哪裡


每次執行會在輸出根目錄建立一個資料夾，副檔名依 --format。只有成功寫入的圖片才會遞增六位數流水號。


+-- tree +
~/Snapparazzi/captures/YYYYMMDD-HHMMSS-PID/
└── App_Name_YYYYMMDD-HHMMSS_000001.jpg
++


截圖只能拍目前桌面上的視窗：視窗最小化、切到其他桌面或關閉時會暫停，同一個視窗回來後自動繼續。App 重新開啟視窗後 ID 會改變，請重新查詢並重新啟動。






錄成影片


把同一個視窗錄成 MP4，可加上 App 的聲音與麥克風。需要 macOS 15 以上；在 macOS 14 上 record 會說明原因並結束。


+-- zsh +
$ snapparazzi record -w 41324 --audio system
已選擇 / selected: Google Chrome — Webinar (ID: 41324)
音訊 / audio: system
輸出 / output: ~/Snapparazzi/recordings/20261031-101530-4821.mp4
錄影中，按 Ctrl-C 停止 / Recording… press Ctrl-C to stop.
^C
正在停止 / Stopping…

Snapparazzi 錄影完成 / recording saved.
  檔案 / file: ~/Snapparazzi/recordings/20261031-101530-4821.mp4 (12.4 MiB)
++


選項


選項說明
-w, --window <id>必填，先用 --list 查
--audio <none|system|mic|both>預設 none（只錄畫面）
--fps <1-60>預設 30
--codec <h264|hevc>預設 h264
--duration <seconds>0.5–86400；省略時按 Ctrl-C 停止
-o, --output <file.mp4>指定 .mp4 路徑，檔案不可已存在
-m, --max-dimension <pixels>等比例縮小，不放大；預設為視窗原始像素
-h, --help錄影專用說明


聲音


system 錄的是目標視窗所屬 App 的聲音，不是整台 Mac：其他 App 的聲音不會錄入，但同一個 App 其他視窗或分頁的聲音可能一起錄入（例如 Chrome 的其他分頁）。DRM 等受保護的內容可能錄不到。


both 會先錄成兩條音軌，停止後再混成一條（各 0.5 增益），影片不重新編碼；停止後要多花幾秒到幾十秒收尾，期間暫時需要約兩倍空間。喇叭外放的聲音會被麥克風再錄一次，建議戴耳機。


麥克風使用開始錄影時的預設輸入裝置，錄影中切換系統預設不會跟著換；裝置被拔除時錄影停止並保留已錄內容。


視窗狀態


    

  • 最小化超過 1 秒改錄黑畫面，還原後自動繼續。
    • 

  • 移到其他桌面或進入 macOS 全螢幕：照常錄製，全螢幕的 Chrome 會填滿畫面。
    • 

  • Chrome 的視窗不在畫面上時會停止繪製網頁影片，錄到的影片區域是黑的。要在背景錄，先完全結束 Chrome（⌘Q），再用這行開啟（只對這次開啟有效）： open -a "Google Chrome" --args --disable-backgrounding-occluded-windows
    • 

  • 調整視窗大小：影片尺寸不變，畫面等比例縮放並貼齊左上角。
    • 

  • 關閉視窗或結束 App：錄影停止並保留已錄內容（結束碼 1）。
    • 



停止與磁碟空間


Ctrl-C 或 --duration 會正常收尾。開始前會檢查磁碟空間（指定 --duration 時依預估大小，否則至少 1 GiB），錄影中剩餘空間低於 512 MiB 會停止並保留已錄內容。錄影中先寫進同一資料夾的隱藏暫存資料夾，檢查完才移到最終路徑，不會覆蓋既有檔案。


+-- tree +
~/Snapparazzi/recordings/YYYYMMDD-HHMMSS-PID.mp4
++


實測：在 Apple silicon、macOS 26.5 以 1280×864、30 fps、H.264、 --audio both 錄一小時（兩次），檔案約 123–130 MiB，CPU 平均約 17–18%，記憶體約 50–60 MiB 且不隨時間增加，音畫同步誤差在 40 ms 以內。






權限與其他


權限


截圖與錄影都需要「螢幕與系統錄音」； record --audio mic 或 both 另需「麥克風」。macOS 通常把權限記在你執行 Snapparazzi 的終端機 App 名下，而不是 snapparazzi 本身，所以換一個終端機可能要重新允許。麥克風權限被拒絕時 mic／both 會直接結束，不會改錄成無聲。


+-- settings +
系統設定 → 隱私權與安全性 → 螢幕與系統錄音 ／ 麥克風
++


Snapparazzi 不會上傳任何資料；圖片與影片只寫入你的 Mac。


更新


snapparazzi update 查詢最新版本，有新版時在本機編譯並取代原本的位置； --check 只查詢。1.3.0 及更早的版本沒有這個命令，請重新執行上面的安裝指令。


同時處理多個視窗


一個程序只處理一個視窗。要同時截取或錄製多個視窗，請開多個終端機分頁，每個分頁跑一個 Snapparazzi，各自可以用不同間隔與輸出資料夾。



  

  




Start here


    

  1. Install
    

    You need macOS 14 or later (15 for recording) and Xcode or its Command Line Tools with the macOS 15 SDK. If you do not have them yet, run xcode-select --install. Then paste this line into Terminal:
    

    +-- install.sh +
    curl -fsSL https://raw.githubusercontent.com/RayChang/snapparazzi/main/install.sh | sh
    ++
    

    It downloads the source, builds it on your Mac and installs it to ~/.local/bin/snapparazzi; a failed build leaves any installed version untouched.
    2. 

  2. Allow screen recording
    

    On first use macOS asks for Screen & System Audio Recording. Allow the terminal app you use (Terminal, iTerm2, Ghostty…) under System Settings → Privacy & Security → Screen & System Audio Recording, then run the command again.
    3. 

  3. Find the window's ID
    

    The number on the left is the window ID. Windows on other desktops or in full screen are listed too, marked "not on this desktop".
    

    +-- zsh +
    $ snapparazzi --list
WINDOW_ID  APP — WINDOW / 應用程式 — 視窗
41324      Google Chrome — Webinar
35239      Calendar — Calendar
46635      Terminal — zsh
42133      Notes — Notes
46504      Google Chrome — YouTube  [不在目前桌面 / not on this desktop]
    ++
    4. 

  4. Start capturing
    

    A screenshot every 2 seconds: snapparazzi -w 41324 -i 2. To record a video instead: snapparazzi record -w 41324 --audio system. Press Ctrl-C to stop; a summary shows where the files are.
    5. 



Quick reference


+-- snapparazzi +
snapparazzi --list                          # list window IDs, incl. other desktops

# Screenshots
snapparazzi                                 # interactive: pick a window and an interval
snapparazzi -w 41324 -i 1.5                 # window and interval
snapparazzi -w 41324 -i 60 -f heic          # use less storage
snapparazzi -w 41324 -i 1 -m 1280           # limit the longest edge

# Recording (macOS 15+)
snapparazzi record -w 41324 --duration 10   # 10 s, video only
snapparazzi record -w 41324 --audio system  # with app audio; Ctrl-C stops
snapparazzi record -w 41324 --audio both -o ~/Movies/demo.mp4  # app audio and mic, to a chosen file

snapparazzi update                          # update to the latest release
snapparazzi --help                          # full help
++






Timed screenshots


Saves the same window as an image every few seconds until you press Ctrl-C. This is what Snapparazzi was built for: keeping a record of every step of an automated run, to look back through one frame at a time. snapparazzi and snapparazzi capture are the same; run just snapparazzi to pick a window from a list and be asked for the interval.


+-- zsh +
$ snapparazzi -w 41324 -i 2
已選擇 / selected: Google Chrome — Webinar (ID: 41324)
間隔 / interval: 2 seconds
格式 / format: jpg
最大尺寸 / max dimension: original
輸出 / output: ~/Snapparazzi/captures/20261031-101530-4821
按 Ctrl-C 停止 / Press Ctrl-C to stop.
✓ Google Chrome_20261031-101530_000001.jpg
✓ Google Chrome_20261031-101530_000002.jpg
✓ Google Chrome_20261031-101530_000003.jpg
^C
Snapparazzi 已停止 / stopped.
  成功 / succeeded: 3
  失敗 / failed: 0
  視窗不可用 / unavailable: 0

Options


OptionDescription
-l, --listList capturable windows and IDs, then exit
-w, --window <id>Window ID; omit to pick from a list
-i, --interval <seconds>Minimum 0.5, decimals allowed; omit to be asked (Enter means 2)
-o, --output <directory>Output root; default ~/Snapparazzi/captures
-f, --format <jpg|heic|png>Image format; default jpg
-m, --max-dimension <pixels>Shrink so the longest edge fits; original size by default, never enlarged
-h, --helpFull bilingual help


File size (measured)


By default it writes full-resolution JPG directly. Choose HEIC for smaller files or PNG for lossless output; -m resizes proportionally with a built-in macOS tool after capture. Measured on 35 Chrome window samples around 2560×1410; the 16-hour column assumes one per second (57,600 images). Actual sizes vary with what is on screen.


SettingAverage16 h at 1 per second
PNG (lossless)1.30 MB74.9 GB
JPG (default)404 KB23.3 GB
HEIC213 KB12.3 GB
JPG + -m 1280136 KB7.9 GB


At one per minute the cost of every format is negligible. At one per second JPG is the best balance of speed and size; HEIC encodes more slowly, and -m adds a resize pass. For storage first:


+-- zsh +
$ snapparazzi -w 41324 -i 1 -f jpg -m 1280
++


Where files go


Every run creates its own folder under the output root; the extension follows --format. The six-digit number advances only after an image is written.


+-- tree +
~/Snapparazzi/captures/YYYYMMDD-HHMMSS-PID/
└── App_Name_YYYYMMDD-HHMMSS_000001.jpg
++


Screenshots only capture a window on the current desktop: while it is minimized, on another desktop or closed, capture pauses and resumes when the same window returns. A reopened window gets a new ID; look it up again and restart.






Recording


Records the window to an MP4, optionally with the app's sound and the microphone. Needs macOS 15 or later; on macOS 14, record explains this and exits.


+-- zsh +
$ snapparazzi record -w 41324 --audio system
已選擇 / selected: Google Chrome — Webinar (ID: 41324)
音訊 / audio: system
輸出 / output: ~/Snapparazzi/recordings/20261031-101530-4821.mp4
錄影中，按 Ctrl-C 停止 / Recording… press Ctrl-C to stop.
^C
正在停止 / Stopping…

Snapparazzi 錄影完成 / recording saved.
  檔案 / file: ~/Snapparazzi/recordings/20261031-101530-4821.mp4 (12.4 MiB)
++


Options


OptionDescription
-w, --window <id>Required; find it with --list
--audio <none|system|mic|both>Default none (video only)
--fps <1-60>Default 30
--codec <h264|hevc>Default h264
--duration <seconds>0.5–86400; omit to stop with Ctrl-C
-o, --output <file.mp4>A .mp4 path that must not exist yet
-m, --max-dimension <pixels>Fit the longest edge, never upscale; native pixels by default
-h, --helpRecording help


Sound


system records the target window's app, not the whole Mac: other apps are excluded, but the same app's other windows or tabs may be included (other Chrome tabs, for example). Protected (DRM) content may not be captured.


both records two tracks and mixes them into one after you stop (0.5 gain each) without re-encoding the video; finishing takes a few extra seconds to a few tens of seconds and briefly about twice the space. Sound from the speakers is picked up again by the microphone, so use headphones.


The microphone is the default input when recording starts, even if the system default changes later; if it is unplugged, recording stops and keeps what it has.


Window state


    

  • Minimized for over a second: records black, resumes when restored.
    • 

  • Moved to another desktop or into macOS full screen: keeps recording, and full-screen Chrome fills the frame.
    • 

  • Chrome stops drawing web video while its window is not visible, so that area records black. To record in the background, quit Chrome (⌘Q) and reopen it with this line (for that launch only): open -a "Google Chrome" --args --disable-backgrounding-occluded-windows
    • 

  • Resized: the video size stays fixed; the picture is scaled to fit, top-left.
    • 

  • Window closed or app quit: recording stops and keeps what it has (exit status 1).
    • 



Stopping and disk space


Ctrl-C or --duration finish normally. Free space is checked first (from the estimated size with --duration, otherwise at least 1 GiB), and recording stops below 512 MiB, keeping what it has. It writes to a hidden staging folder next to the file and moves it into place only after checking it, never overwriting.


+-- tree +
~/Snapparazzi/recordings/YYYYMMDD-HHMMSS-PID.mp4
++


Measured: one hour of 1280×864, 30 fps, H.264 with --audio both on Apple silicon and macOS 26.5 (twice): about 123–130 MiB, ~17–18% CPU, 50–60 MiB of memory that does not grow, and sound within 40 ms of the picture.






Permissions and more


Permissions


Screenshots and recordings need Screen & System Audio Recording; record --audio mic or both also needs Microphone. macOS usually grants these to the terminal app that launches Snapparazzi, not to snapparazzi itself, so another terminal may need its own permission. If Microphone is denied, mic/both exit instead of recording silence.


+-- settings +
System Settings → Privacy & Security → Screen & System Audio Recording / Microphone
++


Snapparazzi uploads nothing; screenshots and recordings stay on your Mac.


Updating


snapparazzi update checks for a newer release and builds it in place; --check only checks. Versions 1.3.0 and earlier do not have it; run the install line again.


Several windows


One process handles one window. To capture several at once, run one Snapparazzi per Terminal tab, each with its own interval and folder.
