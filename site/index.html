只錄一個視窗。


      
原生的 macOS 指令列工具。把一個 App 視窗定時截圖，或錄成 MP4，連同那個 App 的聲音；其他視窗和其他 App 的聲音都不會錄進去。


      

        
在終端機貼上這一行安裝：

        

          
+-- install.sh +

          

            curl -fsSL https://raw.githubusercontent.com/RayChang/snapparazzi/main/install.sh | sh
            
          

          
++

        

        
需要 macOS 14 以上（錄影需要 15）與 Xcode Command Line Tools。安裝程式會在你的 Mac 上編譯原始碼，裝到 ~/.local/bin。

        

      

    


    
  


  

    
三個指令，錄好一個視窗

    
    
      
  1. 
        
    找到視窗的 ID。其他桌面或全螢幕的視窗也會列出來。
    
        
    +-- zsh  1/3 +
    $ snapparazzi --list
WINDOW_ID  APP — WINDOW / 應用程式 — 視窗
41324      Google Chrome — Webinar
35239      Calendar — Calendar
46635      Terminal — zsh
42133      Notes — Notes
46504      Google Chrome — YouTube  [不在目前桌面 / not on this desktop]
    ++
    
      
    2. 
      
  2. 
        
    開始錄。--audio system 錄這個 App 的聲音，mic 錄麥克風，both 兩個都錄。
    
        
    +-- zsh  2/3 +
    $ snapparazzi record -w 41324 --audio system
錄影中，按 Ctrl-C 停止 / Recording… press Ctrl-C to stop.
    ++
    
      
    3. 
      
  3. 
        
    按 Ctrl-C 停止。看到「錄影完成」，影片就存好了。
    
        
    +-- zsh  3/3 +
    ^C
正在停止 / Stopping…

Snapparazzi 錄影完成 / recording saved.
  檔案 / file: ~/Snapparazzi/recordings/20261031-101530-4821.mp4 (12.4 MiB)
    ++
    
      
    4. 
    

    
只要截圖：snapparazzi -w 41324 -i 2，每 2 秒存一張 JPG。全部選項請看 snapparazzi --help 與 snapparazzi record --help。

  


  

    
它會做的事

    
+-- snapparazzi record --help +

    

      
錄成 MP4
H.264 或 HEVC，1–60 fps。用 --duration 指定秒數，時間到自動停止。

      
聲音
--audio none | system | mic | both。system 只錄這個 App 的聲音，其他 App 的通知聲不會進來；both 會混成一條音軌。

      
定時截圖
每 0.5 秒以上一張，存成 JPG、HEIC 或 PNG；-m 1280 限制最長邊。

      
別的桌面與全螢幕
視窗在其他桌面或全螢幕也能直接錄；全螢幕的 Chrome 會填滿整個畫面。

      
停止
按 Ctrl-C 乾淨停止並顯示摘要；視窗關閉時也會停止並保留已錄的內容。

      
更新
snapparazzi update 查詢並安裝最新版本，--check 只查詢。

    

    
++

  


  

    
開始前先知道

    
+-- caveats +

    
    
      
  • 第一次執行時，到「系統設定 → 隱私權與安全性 → 螢幕與系統錄音」允許你用的終端機 App；錄麥克風還要允許「麥克風」。
    • 
      
  • system 聲音是整個 App 的：同一個瀏覽器的其他分頁也會被錄進去。
    • 
      
  • Chrome 的視窗不在畫面上時（切到別的桌面）會停止繪製網頁影片，錄到的影片區域會是黑的。要在背景錄，先完全結束 Chrome，再用這行開啟：open -a "Google Chrome" --args --disable-backgrounding-occluded-windows
    • 
      
  • 受 DRM 保護的內容可能錄不到畫面或聲音。
    • 
      
  • 一個程序只處理一個視窗。要同時錄好幾個，就開好幾個終端機分頁。
    • 
    

    
++

  


  

    
錄完按 Ctrl-C。
